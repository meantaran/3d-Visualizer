# NeuroSphere AI — Interactive 3D Analytics Platform

## Overview

DataSphere AI is a futuristic interactive 3D data visualization platform built using React and modern frontend technologies. The application transforms complex datasets into immersive 3D experiences with real-time analytics, AI-powered insights, particle systems, and cyberpunk-inspired UI design.

This project demonstrates advanced frontend engineering concepts including 3D rendering, motion design, data visualization, responsive layouts, and interactive user experiences.

---

# Features

* Interactive 3D visualization environment
* Real-time animated particle systems
* Orbit camera controls
* Bloom and post-processing visual effects
* Live analytics dashboard
* Dataset upload support
* AI-powered insights panel
* Responsive cyberpunk dashboard UI
* Smooth Framer Motion animations
* Modern dark-mode interface

# Installation

## Clone Repository

```bash
git clone https://github.com/your-username/datasphere-ai.git
```

## Open Project

```bash
cd datasphere-ai
```

## Install Dependencies

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```
